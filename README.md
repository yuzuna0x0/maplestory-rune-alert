# maplestory-rune-alert

사용법
1. 화면공유를 메이플 창을 지정
2. 공유된 화면을 드래그하면 선택 영역을 재지정 할 수 있음(권장 게임 해상도 1920×1080, 1366×768)
3. 필요에 따라 오차범위와 감지 픽셀 수를 조정
4. 선택 영역 미리보기에서 미니맵 상 룬
5. 알림 상태창은 클릭 시 새 창으로 띄울 수 있음
